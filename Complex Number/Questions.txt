1. যদি \(x = 1 + i\sqrt{2}\) হয়, তবে \(x^4 - 2x^3 + 2x^2 + 2x + 5\) এর মান নির্ণয় করো। 
2. যদি \(x = \frac{1 + i}{\sqrt{2}}\) এবং \(y = \frac{1 - i}{\sqrt{2}}\) হয়, তবে \(x^6 + y^6 + x^4 + y^4 + x^2 + y^2 + 1\) এর মান নির্ণয় করো।

3. \[z\]⁠ একটি জটিল সংখ্যা হলে, \(z^2 + \bar{z} = 0\) সমীকরণটির সকল সমাধান নির্ণয় করো।

4.  \(z - 2\vert{}z + 1\vert{} + i = 0\) সমীকরণটি সমাধান করে z-এর মান নির্ণয় করো।

5. z² - (3 - 2i)z + (5 - 5i) = 0 সমীকরণটি সমাধান করো।

6. (z - 1)⁴ + (z + 1)⁴ = 0 সমীকরণটির সকল সমাধান নির্ণয় করো।

7. (z + i)³ + (z - i)³ = 0 সমীকরণটি সমাধান করো।

8.  যদি \(\vert z_1 \vert = \vert z_2 \vert = \vert z_3 \vert = 1\) এবং z₁ + z₂ + z₃ ≠ 0 হয়, তবে \[\left|\frac{z_{1}z_{2}+z_{2}z_{3}+z_{3}z_{1}}{z_{1}+z_{2}+z_{3}}\right|\]⁠ এর মান কত?

9. \(\vert z_1 \vert = 3, \vert z_2 \vert = 4\) এবং \(\vert z_1 + z_2 \vert = 5\) হলে \(\vert z_1 - z_2 \vert\) কত?

10. . যদি \(\vert z_1 + z_2 \vert = \vert z_1 - z_2 \vert\) হয়, তবে প্রমাণ করো যে \[\frac{z_{1}}{z_{2}}\]⁠ একটি বিশুদ্ধ কাল্পনিক সংখ্যা

11. যদি \(\left\vert z + \frac{4}{z} \right\vert = 2\) হয়, তবে \(\vert z \vert\)-এর সর্বোচ্চ ও সর্বনিম্ন মান নির্ণয় করো।

12. যদি \(\vert z - 3 + 4i \vert \le 2\) হয়, তবে \(\vert z \vert\)-এর সর্বোচ্চ ও সর্বনিম্ন মান নির্ণয় করো।

13. যদি \(\vert z - 3 + 4i \vert \le 2\) হয়, তবে \(\vert z + 1 - 2i \vert\)-এর সর্বোচ্চ ও সর্বনিম্ন মান নির্ণয় করো।

14. প্রমাণ করো যে, \(\left(\frac{1 + \cos\theta + i\sin\theta}{1 + \cos\theta - i\sin\theta}\right)^n = \cos n\theta + i\sin n\theta\) (বা \[e^{in\theta }\]⁠)। 

15. মান নির্ণয় করো: \[\left(\frac{1-\cos \theta +i\sin \theta }{1+\cos \theta -i\sin \theta }\right)^{n}\]⁠। 

16. প্রমাণ করো যে, \((1 + \cos\theta + i\sin\theta)^n + (1 + \cos\theta - i\sin\theta)^n = 2^{n+1}\cos^n\frac{\theta}{2}\cos\frac{n\theta}{2}\)

17.  \(x^2 + x + 1 = 0\) সমীকরণের মূলদ্বয় \[\alpha \]⁠ ও \[\beta \]⁠ হলে, \(\alpha^{19} + \beta^7\) এবং \(\alpha^n + \beta^n\)-এর মান নির্ণয় করো।

18. দেখাও যে, \((z + 1)^n - (z - 1)^n = 0\) সমীকরণের সবগুলো মূল কাল্পনিক অক্ষের (Imaginary Axis বা \(x = 0\) রেখার) ওপর অবস্থিত।

19. প্রমাণ করো যে, \((z - 2)^n + (z + 4)^n = 0\) সমীকরণের সবগুলো মূল \(x = -1\) সরলরেখার ওপর অবস্থিত।

20.  জটিল তলে \(\vert{}z - 2 + 3i\vert{} + \vert{}z + 4 - 5i\vert{} = 14\) সমীকরণটি কী নির্দেশ করে? কনিকটির কেন্দ্র, উৎকেন্দ্রিকতা, উপকেন্দ্রিক লম্বের দৈর্ঘ্য এবং ক্ষেত্রফল নির্ণয় করো।

21. যদি \(\vert{}\vert{}z - 3\vert{} - \vert{}z + 3\vert{}\vert{} = 4\) হয়, তবে কনিকটির অসীমতটদ্বয়ের (Asymptotes) মধ্যবর্তী কোণ এবং উপকেন্দ্র থেকে অসীমতটের লম্ব দূরত্ব নির্ণয় করো। 

22. z² + (p + iq)z + r + is = 0 সমীকরণের একটি মূল বাস্তব হওয়ার শর্ত নির্ণয় করো (যেখানে p, q, r, s বাস্তব সংখ্যা)।

23. \(\sum_{k=1}^{6} \left(\sin\frac{2\pi k}{7} - i\cos\frac{2\pi k}{7}\right)\)-এর মান নির্ণয় করো।
